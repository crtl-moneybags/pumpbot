Risk controls

Automation with guardrails you control

The engine is built to pursue short-lived launch opportunities, but live trading is highly competitive. Volatility, congestion, failed transactions, slippage, priority fees and token risk can turn a trade negative. Set strict limits and test every strategy before committing meaningful capital.

FAQ

Questions, answered

What does this tool do?

It is an automated pump.fun trading engine designed to monitor launches, evaluate opportunities against configured rules, coordinate MEV-aware execution settings, manage positions and track performance. Available execution modes and controls depend on your project configuration.

Can it trade automatically?

The strategy workflow is designed to automate launch monitoring, qualifying entries and position management once the required wallet permissions and execution mode are configured. Review the signing or delegation model and all limits before enabling live trading.

Does it guarantee profits?

No. There is no guaranteed profit in MEV, launch sniping or any other trading strategy. Competition, volatility, congestion, failed or delayed transactions, slippage, fees and token-specific risks can all produce losses. Treat performance claims as unverified unless supported by complete, independently reviewable trading records.

What should I configure before going live?

At minimum, review your strategy filters, position size, slippage tolerance, priority-fee ceiling, maximum exposure, exit rules and wallet permissions. Start with conservative limits and validate behavior in a non-live mode before allocating capital.

Can I use an AI agent with the CLI?

The CLI can be integrated into development and operator workflows that run shell commands and read structured output. Keep live execution behind explicit configuration and permission checks; an agent should never be allowed to silently change wallet permissions or risk limits.

Is this affiliated with pump.fun?

No. pump.fun is a third-party platform. This project is independent and is not sponsored by, affiliated with or endorsed by pump.fun or the AI and developer tools shown on this page.

What are the main risks?

You can lose some or all of the capital used by the bot. New-token markets can have extreme volatility, thin liquidity, malicious tokens, congestion, failed transactions and rapidly changing execution costs. Use only capital you can afford to lose and never assume a strategy will remain profitable.
